# Музыкальный агрегатор

## Описание проекта
Проект представляет собой музыкальный агрегатор, который собирает музыку с разных музыкальных сервисов и 
отображает общую статистику (Spotify, Яндекс Музыка, Apple Music, SoundCloud)
